# 🚀 NEROOH.XYZ // Cyberpunk Sci-Fi HUD Portfolio

> Portfolio pessoal e cockpit interativo de **Carlito Batista (Nerooh)** — Engenharia, Automação, Impressão 3D e Desenvolvimento.

---

## 🛰️ Visão Geral

Interface inspirada em consoles espaciais, HUDs futuristas militarizados e computação tática dos anos 80/90 com tecnologia moderna na web:
- **Design HUD Tático:** Efeitos CRT scanline, vinheta óptica, grids vetoriais e animações em Canvas (deformação espaço-tempo interativa).
- **Projetos & Lab:** Vitrine detalhada de engenharia, Klipper, automação ESP8266 e laboratório Maker.
- **Áudio Sci-Fi:** Feedback sonoro sintético procedural via Web Audio API.
- **Responsivo & Otimizado:** Feito em Vanilla HTML5, CSS3 avançado e JavaScript puro (sem frameworks pesados).

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 & Semântica**
- **CSS3 Puro** (Custom Properties, Grid & Flexbox, Filtros CRT, Tipografia Sci-Fi)
- **JavaScript Moderno (ES6+)**
- **HTML5 Canvas & Web Audio API**
- **Fontes:** Orbitron, Chakra Petch, Rajdhani, Share Tech Mono

## 🌐 Como Rodar Localmente

Basta clonar o repositório e abrir o `index.html` em qualquer navegador:

```bash
# Clonar o repositório
git clone https://github.com/Ner00h/nerooh-cyber-hud.git

# Acessar a pasta
cd nerooh-cyber-hud

# Abrir no navegador (ou use a extensão Live Server / npx serve)
start index.html
```
